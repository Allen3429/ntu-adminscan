    這一版怎麼用？
    放單據 → 核對金額與用途 → 取得草稿。
    單一 HTML 可讀 TXT、貼文字或試合成範例。照片／PDF 請使用完整程式包啟動本機服務；選檔後會自動讀取，不需再按一次分析。
    預設不使用付費 API 或雲端模型。資料只留本頁記憶體；原始檔不嵌入匯出的草稿。請先遮去非必要個資。
    目前尚未接通校方製單、送件、簽核與取件服務。畫面不會顯示虛構的受理、核准或付款。
    「完整工作台」是本機工具入口，不是受保護的校方管理後台。
    

    常用資料，少填一次。
    只在本次頁面保留，之後的新草稿會先帶入，仍須逐案確認。
    這不是校方經費授權；留空也能使用。
    

    讀取的文字
