# 行政一掃通 AdminScan

學生開發的行政資料草稿工具，**非臺大官方服務**。本儲存庫是 v1.2.1 靜態網站前端；不是正式報帳、簽章或代辦後台。

## 使用

GitHub Pages 入口：https://allen3429.github.io/ntu-adminscan/

按「先用範例試試」，或貼上去識別文字、讀取 TXT。核對金額與用途後可下載 HTML 草稿。右上「⋯ → 完整工作台」可查手冊參考、執行合成回歸及演練代辦。請勿輸入校務密碼、完整證號、銀行帳號或未經同意的個資。

**照片只在瀏覽器預覽，PDF 可選檔但不顯示頁面內容；兩者皆未在此網站辨識。** 本網站不傳送單據、不接付費 API、不保存雲端案件。不包含先前開發包的 Python OCR 後端。

## 已有功能

- 單一路徑：放文件／文字 → 核對必要資料 → 取得工作草稿。
- 資料修改後使舊確認失效，未知經費保留待確認，不冒充已授權。
- 規則預檢、來源適用範圍、合成案例測試。
- 23 條帶頁碼的歷史手冊參考；原始 PDF 未公開散布。
- 獨立的合成送簽演練：不產生真實核准、收件、付款或通知。
- 案件只留分頁記憶體。刷新或關閉前需自行下載草稿。

## 未接通

NTU SSO、校務製單、正式送件、電子簽核、付款、原件取送、雲端 OCR。沒有校方收件人或合作窗口正在後台接手。來源核讀不等於校方核定；歷史手冊不作現行稅務、投保或採購門檻依據。

## 開發

Node.js 22 或更新版本，無 npm 相依套件：

```sh
npm test
npm run build
npm run preview
```

本機預覽：`http://127.0.0.1:4173/ntu-adminscan/`。

## 部署

`.github/workflows/pages.yml` 在 pull request 執行合成與靜態檢查；合併 main 後僅將白名單 `dist/` 發佈至 GitHub Pages，再以真正的 Chromium 開啟公開 URL 驗證操作。部署成功與測試結果請看 Actions，README 中的目標網址不是成功證明。

部署後測試只使用合成資料，截圖與 JSON 報告留在該次 Actions artifact。它不代表真實行政案件成功率。失敗時保留日誌，不虛構通過。

## 安全界線

- 瀏覽器 CSP 禁止案件網路提交，不放任何服務金鑰。
- 身分登入、案件存取、經費使用、代簽授權是不同層次。
- 使用者確認或本機模擬事件不是校方有效簽章。
- 公開網站程式碼可被查看，不能用前端旗標當正式存取控制。
- 開站仍會向 GitHub 下載資源；託管商的基礎連線紀錄不由本工具控制。
- 若發現問題，請只以合成資料重現，不在公開 issue 上傳真實單據。

詳見網站的「資料處理與服務狀態」。
